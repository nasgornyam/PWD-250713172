BEASISWA UAJY

UAJY menyelenggarakan berbagai program BEASISWA dengan kriteria dan manfaat yang berbeda-beda.

  • Beasiswa Program Sarjana (S1), yaitu Program Seleksi Siswa Berprestasi (PSSB), Beasiswa Program Beasiswa Program Akademik (BPA), dan lain-lain.
  • Beasiswa Program Sarjana (S2), yaitu Basiswa Prestasi Magister (BPM), Beasiswa Magister Unggul (BMU), dan Bima.
  • Beasiswa Prestasi EP Unggul (BEPU).
